# `signatures` key: GritQL function-body folding

Scope: add a `signatures` key to `CONTEXT_PRELOAD.yml` in `index.ts`. Files matched by `files` preload full content. Files matched by `signatures` preload the same source structure with callable bodies folded by GritQL. `files` wins when both keys select one path.

- [ ] In `index.ts`, extend `PRELOAD_CONFIG` with `signatures: Type.Optional(GLOB_LIST)` and change `PreloadConfiguration` to `{ files: string[]; signatures: string[]; contexts: string[] }`, keeping `additionalProperties: false` so unknown keys still fail validation.
- [ ] Update `loadConfiguration()` to read `config.signatures ?? []`, apply the same absolute-pattern rule that presets use for `files` when `ancestors.length > 0`, and merge inherited and own signature patterns in the same order as `files`.
- [ ] Add `type SelectionMode = "full" | "signatures"` and resolve both glob sets in `collectPreload()` through the existing `globby` options (`gitignore`, `TREE_FILE` and `LOCK_FILE_GLOBS` and negated-pattern ignores, `onlyFiles`, `stats`, no symlink following), then build a `Map<string, SelectionMode>` keyed by resolved path, inserting signature matches first and full matches second so `files` wins overlaps without an error.
- [ ] Add a language registry that maps extensions to `{ language, patternFile }` entries for the initial set (`.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.mts`, `.cts`, `.py`, `.rs`, `.go`) and returns `undefined` for any other extension so signature mode can fail with a clear unsupported-language error.
- [ ] Create the GritQL pattern pack under `grit/` (`fold-javascript.grit`, `fold-python.grit`, `fold-rust.grit`, `fold-go.grit`), where each pattern matches only outermost callable nodes and rewrites only the body node to a language-appropriate marker (`{ /* … */ }` or `...`), leaving modifiers, generics, parameters, return types, decorators, and attributes unchanged.
- [ ] Implement the fold engine module: given cwd, an `AbortSignal`, and the signature-mode file list, copy the files into an `mkdtemp` workspace with relative paths and extensions preserved, group them by registry language, run the pinned Grit CLI once per language group with its fold pattern, read back and validate each rewritten file, and remove the workspace in a `finally` block so project files are never modified.
- [ ] Pin and ship the Grit CLI with the package (vendored binary or an npm-distributed Grit package), resolve the executable path relative to the extension, and throw a direct setup error when the executable is missing or cannot run.
- [ ] Thread the two selection modes through the `collectPreload()` pipeline so full-mode files keep the current behavior (explicit-binary image support through `fileTypeFromBuffer`, fatal UTF-8 decode, `File: path` headings) while signature-mode files reject binaries, pass through the fold engine, and are emitted once each as ordinary `TextContent` blocks under the existing directory-then-path sort.
- [ ] Rework byte accounting so `MAX_FILE_BYTES` guards each original input file, `MAX_FILES` counts unique files across both keys, `MAX_TOTAL_BYTES` and the per-block limit apply to emitted blocks after folding, and original bytes are tracked separately from emitted bytes.
- [ ] Extend the `collectPreload()` result with emitted bytes and original source bytes, and update the session-start notification to report both, for example `Context preloaded: 58 files — 91 KB context from 2.4 MB source`.
- [ ] Guarantee failure semantics: unsupported languages, Grit parse failures, non-zero Grit exits, missing transformed outputs, and binary signature matches each throw a distinct descriptive error, and no signature-mode failure ever falls back to full file content.
- [ ] Update `package.json` so `files` includes the `grit/` directory and any new runtime modules, and record the Grit distribution in `dependencies` so `pi install` ships a working fold engine.
- [ ] Extend `test/unit.test.ts` to cover schema acceptance and rejection of the `signatures` key, `extends` merge order and the preset absolute-pattern rule for signature patterns, and full-mode-wins precedence in the selection map.
- [ ] Extend `test/e2e.test.ts` with JavaScript/TypeScript, Python, Rust, and Go fixtures asserting that declarations survive while implementation-only strings disappear, arrows, methods, and constructors fold, nested callables fold once at the outermost body, braces inside strings and comments stay unchanged, project files on disk are unmodified, unsupported languages error, `files` overrides `signatures` for the same path, and total limits are computed from folded bytes.
- [ ] Update `skills/context-preload-authoring/SKILL.md` so the documented schema, merge semantics, and examples include the `signatures` key and its full-mode precedence rule.
- [ ] Run `npm run check` (typecheck, biome, unit and e2e tests) and resolve every failure before the feature is considered complete.
